# 系列学习笔记

先读 **01 基础版**，了解一张图片怎样经过前处理、GPU 推理和后处理。之后的 02–11 都可以独立阅读：每篇从 01 的执行过程出发，解释自己的改动，并统一与 01 比较。

读者只需具备 C++ 和基本图像处理知识。每篇会在用到时说明主机内存、CUDA stream、Graph 等概念，不要求先读其他优化篇。章节号便于索引，不表示必须把优化逐个叠加。

## 共同的比较方式

每篇主表只比较 **01 与本篇方案**，加速比为 `01 请求 P50 ÷ 本篇请求 P50`。数值来自[同一批统一测量](../benchmarks/rtx3060-yolo26m-2026-10-15/README.md)：YOLO26m 的 01 为 **4.547317 ms**，每版 6000 个样本。倍率大于 1 表示延迟降低，小于 1 表示延迟升高；它不是吞吐倍率。

每篇相对 01 可能同时改变前处理位置、传输缓冲区和任务提交方式。文章会交代完整请求的变化；某个开关的单独效果，需要在同一篇的程序内固定其他条件再对照。这样既能回答“比 01 怎样”，也能解释收益究竟可能来自哪里。

01–10 有独立推理程序。11 改写模型图，统一测试使用 09 的注册输入运行方式；11 会在文内解释这条路径，**1.31× 是完整方案相对 01 的结果**。

各篇主表和运行命令统一使用 YOLO26m；[YOLO26n 历史结果](../benchmarks/rtx3060-unified-baseline-2026-09-15/README.md)单独保留，不跨模型计算倍率。

详细采样、资源开销及以往单项实验保留在各篇引用的报告中。需要运行时，直接使用该篇的“01 + 本篇”命令即可；重新构建 engine 后，应重新测量两边。
